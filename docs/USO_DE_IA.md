# Uso de Ferramentas de IA

O grupo utilizou ferramentas de inteligência artificial como apoio ao planejamento,
organização textual e implementação assistida. As decisões finais foram revisadas e
adaptadas pelos integrantes.

| Ferramenta | Fase | Uso |
| --- | --- | --- |
| ChatGPT | Brainstorm, requisitos, personas, documentação e roteiro | Apoio textual, organização de ideias e revisão de clareza |
| NotebookLM | Projeto visual dos slides | Apoio na orientação visual e organização do material de apresentação |
| Google Omni | Planejamento do vídeo | Apoio na estrutura do vídeo e divisão de falas |
| GitHub Codex | Implementação e documentação | Apoio na criação de código, estruturação do repositório e documentação técnica |

## Revisão pelo grupo

O conteúdo apoiado por IA foi revisado pelo grupo para:

- manter coerência com a proposta do BookLog;
- adequar o texto aos requisitos da disciplina;
- remover informações genéricas;
- garantir que personas, cenários e telas refletissem o projeto;
- organizar o repositório de forma compreensível para avaliação.

## Fases apoiadas por IA

- Análise de requisitos: apoio para organizar requisitos funcionais e não
  funcionais.
- Projeto: apoio para estruturar personas, cenários e wireframes.
- Implementação: apoio para gerar componentes, telas e dados mockados.
- Testes: apoio para listar cenários de validação.
- Documentação: apoio para compor README, relatório, roteiro e documentos
  complementares.
