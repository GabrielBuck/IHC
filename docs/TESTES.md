# Testes

Os testes desta entrega foram planejados para validar navegação, clareza visual e
acessibilidade básica do protótipo front-end.

| ID | Funcionalidade | Cenário testado | Resultado esperado | Status |
| --- | --- | --- | --- | --- |
| T01 | Login visual | Usuário toca em Entrar | Acessa a tela Início | Validado no protótipo |
| T02 | Cadastro visual | Usuário toca em Criar conta e depois Cadastrar | Acessa o fluxo principal | Validado no protótipo |
| T03 | Navegação para feed | Usuário seleciona Início na barra inferior | Feed com progresso e resenhas aparece | Validado no protótipo |
| T04 | Busca de livros | Usuário abre Buscar | Campo, filtros e lista de livros aparecem | Validado no protótipo |
| T05 | Detalhes do livro | Usuário toca em um card de livro | Tela de detalhes exibe sinopse e ações | Validado no protótipo |
| T06 | Biblioteca | Usuário abre Biblioteca | Livros aparecem separados por status | Validado no protótipo |
| T07 | Resenha | Usuário abre Escrever resenha | Nota, campo de texto e botão aparecem | Validado no protótipo |
| T08 | Perfil | Usuário abre Perfil | Estatísticas, gêneros e atividades aparecem | Validado no protótipo |
| T09 | Grupos | Usuário abre Grupos | Grupos, livros atuais e participantes aparecem | Validado no protótipo |
| T10 | Configurações | Usuário abre Ajustes | Opções de acessibilidade e preferências aparecem | Validado no protótipo |
| T11 | Contraste visual | Usuário lê cards e botões | Texto permanece legível em fundo claro | Planejado/validado no protótipo |
| T12 | Labels de acessibilidade | Leitor de tela acessa ações principais | Botões possuem rótulos descritivos | Planejado/validado no protótipo |
| T13 | Botões com área de toque confortável | Usuário toca em ações principais | Botões têm altura e padding adequados | Planejado/validado no protótipo |
| T14 | Coerência entre telas | Usuário percorre fluxo completo | Cabeçalhos, cards e botões mantêm padrão | Validado no protótipo |

## Observações

Como a entrega usa dados mockados, os testes não validam persistência real, API ou
autenticação. Esses pontos fazem parte da evolução futura da arquitetura.
